# Café Crema — Demo Website (Light Edition)

Static demo website for Café Crema, Saki Naka, Andheri East (@cafecrema__).

- Dishes showcase with category filters
- Table reservation form
- Plain HTML, CSS and JS — no build step

## Upload to GitHub
1. Create a new repository on GitHub.
2. Upload all files from this folder (keep them at the top level).
3. Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be live at `https://<username>.github.io/<repo>/`.
